# VisióndeFútbol

Sitio web estático enfocado en noticias, estadísticas y contenidos del fútbol internacional. 

## Estructura principal

- **index.html** – página de inicio con slider de noticias.
- **noticias.html** – listado de noticias filtrables.
- **equipos.html** – información básica de equipos.
- **jugadores.html** – perfiles de jugadores destacados.
- **partidos.html** – calendario y resultados recientes.
- **galeria.html** – galería de imágenes.
- **contacto.html** – formulario de contacto con validación.

Los estilos globales se encuentran en `css/style.css` y los ajustes responsivos adicionales en `css/responsive.css`. El comportamiento general se maneja desde `js/main.js`.

Para visualizar el sitio basta con abrir cualquiera de los archivos HTML en un navegador moderno.
